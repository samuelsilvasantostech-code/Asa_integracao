Clientes

Cada cliente é uma clínica: um sistema (ERP), uma chave de instalação única e as configurações dela. Clique num cliente para abrir a ficha.

Roteiro de implantação
  1. + Novo cliente: o assistente cria a clínica, liga o sistema (ERP), testa o acesso e mostra a chave da instalação (ela aparece uma vez só).
  2. Instalar a extensão na Kentro da clínica pela URL do manifest. Na instalação, cole a chave em apiKey, preencha queueIds e restrinja o público a quem vai testar.
  3. Anotar o id da instalação (último passo do assistente, ou aba Instalação do cliente).
  4. Sistema fora da lista: anexe a documentação no assistente ou na aba Sistema. O conector é preparado em Sistemas (ERP) e, publicado, a clínica liga.
  5. Configurar financeiro e confirmação, se a clínica for usar, e então abrir o público da instalação para toda a equipe.

    Qual sistema a clínica usa (a lista vem de Sistemas (ERP)) e, se quiser, outro nome nas telas. Os campos de acesso são os que o sistema pede: são testados antes de gravar, ficam cifrados e não voltam para esta tela. Para manter o acesso já gravado, deixe os campos em branco.

    Token da Asa

    Normalmente a própria clínica cola o token em ClinFy → Configurar. Use aqui para cadastrar ou trocar o token. Ele é validado na Asa e guardado cifrado; não volta para esta tela.

    Documentação do sistema

    Para sistema sem documentação aberta: anexe aqui o que a clínica ou o fornecedor mandar (OpenAPI/Swagger, coleção do Postman, PDF ou link). Vai para o conector do sistema, em Sistemas (ERP), e é a base para ler a API e personalizar a extensão. Credenciais dentro de coleções JSON são apagadas ao receber.

        Sistemas (ERP)

        Os conectores de cada sistema de gestão e os pedidos de sistemas que ainda não têm conector.

        Como funciona

        Um conector por sistema: ele traduz as rotas da especificação ClinFy para as do sistema. Caminho: rascunho → homologação (uma clínica liga para testar) → publicado (aparece para todas as clínicas).

        Os pedidos chegam das clínicas (Outro / não encontrei) e do assistente de novo cliente. Crie o conector a partir do pedido, anexe a documentação e acompanhe até publicar.

        Sistemas que ainda não têm conector. "Criar conector" já preenche o nome; "Abrir conector" leva direto a ele.

                Como funciona

                O "uso" soma as ações na agenda, as cobranças e os atendimentos com tempo de espera; as setas comparam com o período anterior de mesmo tamanho. O selo resume a saúde da clínica: Crítica quando há alerta crítico, Atenção quando há aviso. Clique numa clínica para ver o painel dela. Mede só o que passou pela extensão, não a agenda inteira da clínica. Atendentes distintos valem só para os últimos 90 dias (a retenção apaga os nomes depois disso). Buscas de paciente, telas abertas, falhas do sistema (ERP) e a versão da extensão são contados desde a versão 0.35.0.
